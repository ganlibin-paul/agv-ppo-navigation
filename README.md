# AGV PPO Navigation

这是一台双驱动轮AMR的局部绕障工程：原导航负责正常行驶，遇障停稳后由PPO残差控制与扫描净空检查接管，绕过障碍、回到路径后交还原导航。

仓库同时提供 **Isaac Sim训练/验证** 和 **ROS 1真机集成**。本次整理日期为2026-11-09；它不是把实验策略自动升级到真机的安装器。

## 当前能证明什么

|版本|用途|状态|
|---|---|---|
|V85 + V33权重/V35 NumPy推理|历史真机接管集成|已有部署记录；静态单/双箱现场有成功记录，不代表任意布局稳定|
|V94|16环境域随机化PPO长训|262144步，64组验证23组到点，三箱40组12组成功，全部零接触；**不作为新真机部署模型**|
|V95|路径接续与终点朝向修复|冻结V94模型进行8场景×2控制器配对验证；本仓库未宣称验收通过|

本次V94测试最小车身到箱子净空约0.2013米、到侧墙约0.2584米。无接触但停滞不算成功，失败间距也不能证明物理上不可能通过。详见[结果与限制](docs/RESULTS.md)。

## 本地工件验证

在有NumPy的Python 3环境中执行：

```bash
python tools/check_release.py
```

此命令校验模型SHA256、复用真实编码器和NumPy actor跑合成回归，不连接ROS、不发布速度。ROS运行依赖见部署文档，不能用普通`pip install`替代ROS环境。

未随仓库上传：机器人USD/网格、Isaac Sim安装包、V92/V94训练检查点、现场地图与ROS采集、SSH凭据。历史小型actor已包含，不需要从训练ZIP直接在Python 2.7车端加载。

项目保持私有；本次没有授予第三方开源许可。机器人厂商资源和NVIDIA软件的使用许可由资源持有者分别确认。
