# 本车输入契约与几何

## ROS输入

|输入|历史话题/接口|作用|
|---|---|---|
|合并激光|`/merged_scan` LaserScan|1083束，base_footprint候选栅格|
|双原始激光|`/scan`, `/scan_back`|原始角度和量程、可见自由空间、融合|
|里程计|`/odom`|线速度、角速度与时间|
|地图定位|TF查询|定位与路径统一到map坐标|
|路径|`/nav_plan` nav_msgs/Path|站点路径几何|
|任务|`/path_nav_status` std_msgs/String JSON|活动任务ID及状态|
|当前地图|`/current_map_id` lyric_msgs/CurrentMapId|获取对应地图|
|地图查询|`/get_json_map_data_service` lyric_msgs/GeneralJsonServer|只读查询GetAgvMapById，匹配路径/站点|
|原导航参考|`/yocs_cmd_vel_mux/input/navigation` Twist|v_ref/w_ref及遇障停车上下文|
|运行状态|`/safe_param`, `/drive_status`, `/yocs_cmd_vel_mux/active`|接管/覆盖判断|
|实际mux输出|`/output/cmd_vel`|核对命令是否被采纳|

车端还需要`rospy`、`tf`、sensor_msgs/nav_msgs/geometry_msgs/std_msgs，以及现场`lyric_msgs`定义。安装ROS标准包不能自动补出厂商自定义消息/服务。

## 164维观测顺序

精确实现以`runtime/model_codec_v10.py`为准：

|组成|维数|
|---|---:|
|72扇区归一化最近距离|72|
|72扇区有效位|72|
|有效束比例、最近距离、最近方向sin/cos|4|
|横向误差、朝向sin/cos、曲率、前视距离、进度、方向|7|
|参考/实测v、w、时间差|5|
|前两次动作，旧到新|4|
|合计|164|

激光要求1083束，angle_min=-3.14，increment=0.0058；有效量程0.05～50米，无效哨兵51。真实增量和束数是契约，不应为了“看起来360度”任意重采样；`angle_min + 1082*increment ≈ 3.1356`，与宣传性的±π需区分。原双激光仿真各1440射线，不能将融合1083束等同于单雷达本体分辨率。

归一化尺度：距离3米、v=1.5m/s、w=0.58rad/s、e_y=1.5米、ld=1.2米、曲率2、时间差0.5秒。任务速度上限不是归一化分母。`direction=0`代表当前前进路径；反向任务不在该策略范围。

## 动作

候选归一化动作两维，残差大意为`v_ref+0.4*a_v`、`w_ref+0.2*a_w`，再执行速度及变化率限制、扫描投影。对应精确实现见`input_bridge_v6.py`与实际adapter调用顺序。历史真机接管上限0.2m/s，局部规划跟随前进上限0.12m/s；原导航速度不由这个上限整体改写。

## 本车几何与已知差异

仿真评估采用旋转车体平面矩形0.975×0.703米，车体坐标前沿+0.500、后沿-0.475、左右±0.3515米；轮距0.66米、轮半径0.08米。距离报告是车身外沿到箱体外沿，不是轮中心或雷达原点距离。

尺量发现前激光的候选水平偏移约0.45米；历史生产TF/仿真名义值约0.538米，存在差异。V85在采集/融合适配层显式使用`--front-x-candidate .45`，未修改原车生产TF。复制到另一台车前必须重新量测，不能把本车修正通用化。

接口结构经过核对不代表所有输入分布一致：L1内部字段仍有候选/代理来源、扫描遮挡和时延未完全标定，仿真域随机化范围是设计压力范围。自由点任务只读影子模式与站点前进任务接管范围不同，不应将新地图的自由点默认当成可运动部署任务。
